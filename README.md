# Omarchy Cyberpunkui Theme

A high-contrast Cyberpunk theme for [Omarchy](https://omarchy.org/).

![Cyberpunkui Preview](preview.png?v=2)

## Installation

Install directly in Omarchy using the theme installer:

```bash
omarchy theme install https://github.com/chacechin/omarchy-cyberpunkui-theme.git
```

Or open the Omarchy theme menu:
- Press `Super + Space` (or `Super + Alt + Space`), then go to **Install > Style > Theme** and paste the repository URL.

## Features

- **Cohesive Cyberpunk Palette**: High-contrast cyan, red, and neon accents matched to terminal, shell, status bar, and app styling.
- **Readable Candidate Styling**: Fine-tuned for Fcitx5 and IME input readability with high contrast.
- **Bundled Wallpapers**: Includes a full collection of curated cyberpunk backgrounds.
